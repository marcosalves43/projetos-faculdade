# 📚 Projetos da Faculdade

Repositório destinado ao armazenamento e organização dos projetos, trabalhos e atividades desenvolvidos durante a faculdade.

Aqui estão reunidos projetos realizados ao longo da graduação, envolvendo diferentes áreas da tecnologia e permitindo acompanhar minha evolução durante o curso.

## 🎓 Sobre o repositório

Os projetos foram desenvolvidos como parte das atividades acadêmicas, colocando em prática conhecimentos adquiridos nas disciplinas.

Entre os principais conteúdos trabalhados estão:

* Programação
* Desenvolvimento Web
* Desenvolvimento de Sistemas
* Git e GitHub


## 💻 Tecnologias

As tecnologias utilizadas variam de acordo com cada projeto, incluindo:


* HTML
* CSS
* JavaScript
* Git
* GitHub


## 📂 Organização

Cada pasta ou projeto representa uma atividade, trabalho ou projeto desenvolvido durante a faculdade.

O repositório será atualizado conforme novos projetos forem realizados ao longo do curso.

## 📈 Objetivo

Além de organizar os trabalhos acadêmicos, este repositório serve como registro da minha evolução na área de tecnologia, reunindo experiências práticas e conhecimentos adquiridos durante a graduação.
