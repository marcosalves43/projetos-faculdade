# Pizzaria PI - Página Intermediária de Atendimento

## Sobre o Projeto

Este projeto foi desenvolvido para o Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas.

O objetivo do sistema é melhorar o atendimento digital de uma pizzaria através de uma página intermediária simples e intuitiva, facilitando a navegação de clientes que possuem dificuldade em utilizar sistemas online de pedidos.

---

## Problema Identificado

Atualmente a pizzaria utiliza um sistema de pedidos online acessado através do WhatsApp. Porém, alguns clientes apresentam dificuldades na utilização da plataforma, ocasionando desistência de pedidos e perda de vendas.

---

## Solução Proposta

Desenvolver uma landing page intermediária contendo:

* acesso rápido ao WhatsApp;
* visualização do cardápio;
* promoções;
* atendimento rápido;
* interface moderna e responsiva.
